# Moodmotion Emoji Slider

Open `index.html` in a modern browser. No build step or server is required.

## Controls
- Previous / Next: move through the 16 moods.
- Play / Pause: toggle automatic mood changes.
- Auto Speed: choose slow, normal, or fast.
- Surprise me: jump to a random mood.
- Heart button: save or unsave the current mood in this browser.
- Sound: enable/disable short mood-change chimes (off by default).
- Ambient: enable/disable a soft generated ambient tone (off by default).
- Fullscreen icon: expand only the emoji card; press Escape to return.
- Theme icon: switch between dark and light themes.
- Keyboard: left/right arrows navigate; Space toggles autoplay.
- Touch: swipe left/right on the card.

Saved moods use this browser's local storage. Audio starts only after you turn it on.
